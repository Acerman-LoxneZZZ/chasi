Технические первичные источники реализации: [Three.js](https://threejs.org/docs/), [React](https://react.dev/), [Vite](https://vite.dev/), [Blender Python API](https://docs.blender.org/api/current/), [Codex MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli). Источники навыков перечислены отдельно в `SETUP_REPORT.md`.

Текущая версия KARpOV использует React / Three.js / OrbitControls / GLTFLoader + GSAP ScrollTrigger + Lenis. Пять остановок описаны чистой функцией storyTimeline; геометрия, камера и подписи следуют одному raw-progress через pose mapping. Коммерческие рендеры дополняют основную живую 3D-сцену. Нижние блоки баланса, головки и передачи теперь тоже используют реальные WebGL-модели; один общий дополнительный renderer переносит canvas между видимыми секциями. [Изолированная браузерная проверка](docs/evidence/detail-manager.json) относится к модулю, а актуальный итог всей страницы — к `docs/VERIFICATION.md`. Бренд KARpOV задан пользователем; надпись реально изменена в геометрии циферблата, крышки и платины. Доказательство сохранения остальных 44 мешей — `docs/evidence/karpov-model.json`.

Blender использован локально через CLI/Python. Облачная генерация, публикация, выдуманные цены, запас хода и наличие товара не добавлялись. Скачиваемая карточка сохраняет выбор исполнения и не выдаётся за оформленный заказ.
