# KARpOV — карманная коллекция №01

Коммерческая презентация авторских карманных часов: живая 3D-история с пятью остановками, разделы о характере коллекции, материалах и механике, выбор исполнения корпуса и спецификация. Бренд **KARpOV** нанесён на настоящую геометрию циферблата, внутренней крышки и платины.

Сайт использует React / TypeScript / Vite, Three.js, GSAP ScrollTrigger и Lenis. Все модели, шрифты и изображения локальные. Серверная часть для просмотра не требуется.

## Запуск

Нужен Node.js 22.12 или новее. В папке проекта:

```bash
./start.sh
```

Адрес: **http://127.0.0.1:4173/**. Если зависимости или сборка отсутствуют, скрипт подготовит их. После изменения исходников сначала выполните `npm run build`. Для разработки — `npm run dev`, адрес http://127.0.0.1:5173/. На другом компьютере: `npm ci`, `npm run build`, `npm run preview`.

Для 3D нужен современный браузер с WebGL 2. При ошибке модели или недоступном WebGL остаются изображение, объяснение и доступная коммерческая часть страницы. Blender и Python для просмотра не нужны. Облачная публикация и Git push не выполнялись.

## Что работает

- **Пять остановок:** «Облик», «Корпус», «Циферблат», «Механизм», «Целое». Это настоящие интервалы неподвижной позы, а не только смена текста. Между ними камера и детали плавно переходят к следующему состоянию; обратная прокрутка проходит тем же путём. Кнопки этапов ведут к соответствующим остановкам.
- **3D-обзор:** камера проходит 423° на desktop и 407° на телефоне, приближается к передаче для макро-плана и возвращается к общей композиции. В макро края корпуса намеренно выходят из кадра.
- **Рассмотреть:** ручное вращение OrbitControls, прямой ползунок истории, сборка/разборка, пауза и сброс камеры. Режим и выбранная конфигурация сохраняются при переходе обратно в историю. Каталог в native dialog позволяет выбрать все 47 групп.
- **Выбор корпуса:** латунь, сталь и графит меняют PBR-материалы корпуса в живой сцене и соответствующее изображение в разделе выбора. Эмаль, стрелки и механизм сохраняют свои материалы. Выбор запоминается в localStorage, если хранилище доступно.
- **Сохранить выбор:** скачивает текстовую карточку выбранного исполнения. Это локальное сохранение, без отправки данных, оформления заказа или оплаты. Цены, наличие, запас хода и водозащита не выдуманы.
- **Нижние разделы:** предметные рендеры, макро материалов, открытый механизм, SVG-схема передачи, спецификация и финальная композиция бренда. Их движения привязаны к прокрутке. Системная настройка уменьшения движения отключает параллакс и длинную 3D-историю по умолчанию.

## Как устроено движение

Lenis сглаживает колёсную прокрутку через общий GSAP ticker; ScrollTrigger передаёт единственный canonical **raw progress**. `evaluateStoryPose` преобразует его в **pose progress** с выдержками. Одинаковое преобразование применяется в истории и ручном режиме, поэтому смена владельца не меняет конфигурацию часов.

| Остановка | Интервал raw progress | Неподвижная pose progress |
| --- | ---: | ---: |
| Облик | 0–10% | 0% |
| Корпус | 22–34% | 22% |
| Циферблат | 47–59% | 46% |
| Механизм | 72–84% | 75% |
| Целое | 94–100% | 100% |

Промежутки соединены quintic smootherstep. Дополнительного визуального follower и второго владельца позы нет. WebGL рисует по требованию; программные переходы останавливаются в скрытой вкладке. Подробнее — [дизайн](docs/DESIGN.md) и [модель](docs/MODEL.md).

## Файлы

- `src/app/App.tsx` — 3D-презентация, остановки и общая конфигурация.
- `src/components/CollectionPage.tsx` — коммерческие разделы, выбор и скачивание карточки.
- `src/data/collection.ts` — тексты остановок и три исполнения.
- `src/animation/storyTimeline.ts` — выдержки и преобразование raw → pose.
- `src/scene/WatchScene.ts` — загрузка GLB, материалы, камера, выбор деталей и подписи.
- `public/models/pocket-watch.glb` и `assets/blender/pocket-watch.blend` — реальная модель KARpOV.
- `public/images/karpov-*.webp` — пять предметных рендеров из этой модели; воспроизведение через `scripts/render-product.mjs`.

Экспорт: **47 групп, 187 898 треугольников, 136 примитивов, 5 324 520 байт**. При ребрендинге изменены только три меша с надписями; остальные 44 меша и весь манифест сохранены. [Проверка модели](docs/evidence/karpov-model.json), [происхождение рендеров](docs/evidence/karpov-renders.json).

## Проверки и сохранение

В текущей KARpOV-итерации подтверждены **54/54 unit-теста**, 6 файлов: [unit-karpov.json](docs/evidence/unit-karpov.json). Новый браузерный набор проверяется отдельно; отчёты прежней fullscreen-версии не доказывают новую страницу. Актуальное состояние QA и ограничения — в [VERIFICATION.md](docs/VERIFICATION.md).

```bash
npm run typecheck
npm test -- --reporter=json --outputFile=docs/evidence/unit-karpov.json
npm run verify:model
npm run build
PW_BASE_URL=http://127.0.0.1:4173 npm run test:browser
```

Playwright использует установленный `/usr/bin/google-chrome`; другой путь задаётся через `CHROME_BIN`. SwiftShader и мобильная эмуляция не являются замером аппаратного GPU или проверкой физического телефона.

```bash
python3 scripts/package-release.py
python3 scripts/save-checkpoint.py
```

Готовый архив — `artifacts/hod-vremeni.zip`; резервные копии — `artifacts/checkpoints/latest.zip` и `previous.zip`. Скрипт checkpoint атомарно обновляет ZIP и проверяет CRC. Версия до KARpOV сохранена отдельно: Git **ef14d61**, `artifacts/checkpoints/before-karpov.zip`.

После выключения компьютера файлы, Git и ZIP остаются на диске, сервер запускается заново через `./start.sh`. Точка продолжения — [WORK_STATE.md](WORK_STATE.md), инструкции — [AGENTS.md](AGENTS.md). В архивы не включаются `.git`, `.tools`, `node_modules`, настройки аккаунтов и env-файлы.

Модель — авторская демонстрационная конструкция, без заявления инженерной точности конкретного исторического механизма. Стрелки стоят на 10:10 для предметной композиции; симуляция реального хода и звук не реализованы.
