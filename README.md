# Ход времени

Локальная интерактивная экспозиция механических карманных часов. На странице остаётся одна полноэкранная 3D-сцена: крупные часы совершают полный оборот и раскрывают механизм при прокрутке. Управление свёрнуто, а каталог всех 47 узлов открывается в боковом диалоге. Режим «Рассмотреть» позволяет остановиться и вращать предмет вручную.

Архив `artifacts/hod-vremeni.zip` содержит исходники приложения, редактируемую модель, статическую сборку, документацию и снимки; он обновляется командой `python3 scripts/package-release.py`. Архив, `dist/`, установленные зависимости и локальные настройки инструментов не хранятся в Git. Сборка воспроизводится из исходников и `package-lock.json`.

## Текущая fullscreen-итерация

Основа задания — [PROMPT_REDESIGN_SCROLL_WATCH.md](PROMPT_REDESIGN_SCROLL_WATCH.md). По последним уточнениям пользователя нижние справочные секции удалены, canvas занимает весь viewport, а прозрачные элементы интерфейса размещены по углам. На desktop камера совершает абсолютный обход **423°**, на телефоне — **407°**, с умеренными наклоном и креном. В кадре 1440×1000 собранный силуэт занимает примерно 845 px по высоте вместо прежних примерно 523 px.

Плавность обеспечивают quintic smootherstep и короткий render-only follower до 100 ms. Он смягчает скачки колеса мыши и точно сходится к единственному canonical progress; очереди tween и искусственная инерция документа не используются. При медленном рендере дольше 90 ms визуальный хвост отключается, чтобы не растягивать догоняние на секунды.

В этой итерации **геометрия не пересоздавалась**: используются прежние детализированные GLB, `.blend` и 47 групп. Их фаски, прорези стрелок, углубление малых секунд и ленточная пружина сделаны в предыдущей геометрической итерации. Экспорт остаётся прежним: 188 570 треугольников, 136 примитивов, 5 345 484 байта. Сведения о текущей сборке и фактических браузерных проверках находятся в [отчёте](docs/VERIFICATION.md).

## Сохранение и продолжение после выключения

[WORK_STATE.md](WORK_STATE.md) хранит состояние проекта, результаты проверок и точку продолжения. [AGENTS.md](AGENTS.md) указывает следующему запуску агента прочитать этот файл. Исходники и локальные Git-коммиты остаются на диске; сервер после выключения запускается снова через `./start.sh`.

```bash
python3 scripts/save-checkpoint.py
```

Команда атомарно обновляет `artifacts/checkpoints/latest.zip`, проверяет CRC и сохраняет предыдущую версию как `previous.zip`. Внутри есть время UTC, Git HEAD, исходники, сборка, модель и документация. Она не выполняет сетевых запросов и не включает установки инструментов или настройки аккаунтов. Готовый архив для передачи отдельно обновляется командой `python3 scripts/package-release.py`.

## Запуск

Нужен Node.js 22.12 или новее. Откройте терминал в папке проекта и выполните:

```bash
./start.sh
```

Скрипт сам выполнит `npm ci` и `npm run build`, если зависимости или сборка отсутствуют. В исходной локальной рабочей папке они уже подготовлены.

Адрес приложения: **http://127.0.0.1:4173/**. Скрипт откроет браузер, если в системе доступен `xdg-open`. Остановить сервер можно сочетанием Ctrl+C. Также в папке есть ярлык `Ход времени.desktop` для запуска приложения в терминале. Публичная публикация не выполнялась.

Режим разработки с обновлением при изменениях:

```bash
npm run dev
```

Адрес разработки: http://127.0.0.1:5173/. Для воспроизводимой установки на другом компьютере с Node.js 22.12+ — `npm ci`, затем `npm run build` и `npm run preview`. Единственный менеджер пакетов проекта — npm; точные версии фиксирует `package-lock.json`.

Для просмотра нужны современный браузер и WebGL 2. **Blender, Python и MCP для работы сайта не нужны.** Все необходимые ресурсы, включая шрифты, модель и изображение на случай ошибки, локальные. При недоступном WebGL показываются изображение и объяснение, а неработающие элементы управления отключаются.

## Управление

- **История** — режим по умолчанию. Обычная прокрутка управляет разборкой и полным обходом камеры; вертикальный свайп по часам прокручивает документ. Высота секции — 600svh на desktop и 450svh на телефоне; sticky-экран занимает 100svh.
- **Управление:** откройте свёрнутую панель в нижнем левом углу. В ней находятся range, кнопки, reset и переключатель подписей. Escape закрывает панель и возвращает фокус её заголовку.
- **Разборка часов:** нативный ползунок 0–100% с шагом 0,1%. Arrow меняет значение, Home собирает, End разбирает. В истории он перемещает документ к соответствующему месту. Из-за округления scroll до CSS-пикселя progress может отличаться от выбранного процента на долю пиксельного шага.
- **Собрать / Разобрать:** в истории запускают переход документа; **Пауза** прекращает его. Wheel, touch и клавиатурный ввод сразу прерывают программное движение.
- **Рассмотреть:** сохраняет именно текущую видимую позу и камеру. Lenis останавливается в текущей позиции, поэтому ползунок соответствует остановленному кадру. Прокрутка больше не меняет модель; работают прямой range, кнопки и вращение мышью/пальцем. Колесо и два пальца приближают только внутри сцены этого явно выбранного режима.
- **Продолжить историю:** синхронизирует документ с ручным progress и плавно возвращает только камеру в сценарный ракурс, сохраняя конфигурацию часов.
- **Сбросить вид:** восстанавливает камеру, сохраняя степень разборки.
- **Подписи деталей:** по умолчанию выключены, чтобы предмет занимал экран. Их можно включить в панели управления. На desktop показываются максимум две в свободных полях; на телефоне — максимум одна в области под canvas. Скрытые узлы не просвечивают подписями.
- **Детали часов:** кнопка в верхнем углу открывает native dialog с каталогом 47 групп и описанием выбранного узла. Открытие включает ручной режим. Клик по детали в сцене также открывает этот диалог. Escape или кнопка закрытия возвращают к предмету; кнопка снятия выделения убирает выбор.

При настройке ОС «Уменьшение движения» сайт сразу предлагает компактный ручной режим без длинной секции. Кнопки устанавливают конфигурацию сразу; ручной ползунок работает напрямую. Историю можно включить явно, при этом автоматический обход камеры отключён. Скрытая вкладка останавливает программные переходы. Resize сохраняет режим и progress; перезагрузка учитывает сохранённую позицию истории.

## Что внутри

React, TypeScript, Vite, Three.js, GSAP ScrollTrigger и Lenis; серверная часть не требуется. `ScrollCoordinator` связывает Lenis с GSAP ticker, а ScrollTrigger передаёт одному `ProgressController` положение истории. В ручном режиме координатор отсоединяется. Чистая функция вычисляет позиции, quaternion и многооборотные углы колёс из проверенного манифеста, без накопления смещений.

Lenis сглаживает колёсную прокрутку. ScrollTrigger, интерфейс, детали и камера используют один progress без вторичного визуального follower. Ручной режим и reduced motion получают точные позы напрямую. Камера вписывает реальные границы мешей на общих планах. На 54–96% истории следует отдельный dolly к центральному колесу: приближение, короткая макро-пауза на 72–78%, отъезд. Края корпуса в этом фрагменте намеренно выходят из кадра; на телефоне приближение мягче. Three.js рендерит по требованию; при медленном draw DPR может снижаться до 0,85 на desktop и 0,9 на телефоне. Детальная геометрия сохраняется.

- `src/app/` и `src/components/` — интерфейс, управление и сведения об узлах.
- `src/scene/` — загрузка GLB, студийный свет, материалы, камера, выбор и подписи с учётом перекрытия.
- `src/animation/` — абсолютные трансформации, canonical progress, общий координатор Lenis / ScrollTrigger.
- `src/data/story.ts` — шесть этапов и короткие функции видимых узлов.
- `src/data/watch-parts.json` — манифест всех 47 деталей и русские объяснения.
- `public/models/pocket-watch.glb` — готовая автономная 3D-модель.
- `assets/blender/pocket-watch.blend` — редактируемый исходник.
- `assets/blender/build_watch.py` и `export_watch.py` — воспроизводимые создание и экспорт; подробности в [docs/MODEL.md](docs/MODEL.md).
- [SETUP_REPORT.md](SETUP_REPORT.md) — проверка 48 навыков и подготовка окружения.
- [docs/BLENDER_MCP.md](docs/BLENDER_MCP.md) — реальная MCP-проверка и граница обнаружения инструментов текущей сессией Codex.
- [ASSET_SOURCES.md](ASSET_SOURCES.md) — происхождение ресурсов и лицензии.
- [docs/VERIFICATION.md](docs/VERIFICATION.md) — фактические проверки и ограничения QA.
- `docs/screenshots/` — desktop/mobile на 0/25/50/75/100% и сравнение с исходной моделью.

## Проверки

Для версии GSAP / Lenis прошли **50/50 unit-тестов** и сделаны 20 новых снимков. Подтверждены 10 browser-сценариев: 9 в полном прогоне и 1 целевым повтором после исправления ожидания в тесте; актуальный статус и методику смотрите в [VERIFICATION.md](docs/VERIFICATION.md).

```bash
npm run typecheck
npm test
npm run verify:model
npm run build
```

Браузерная проверка при запущенном локальном сервере:

```bash
PW_BASE_URL=http://127.0.0.1:4173 npm run test:browser
```

В этом окружении Playwright использует установленный `/usr/bin/google-chrome`. На другой машине путь можно передать через `CHROME_BIN`. Эмуляция мобильного viewport не заменяет проверку на физическом телефоне.

Повторяемая серия из 20 снимков и измерений проекции при запущенном сервере:

```bash
PW_BASE_URL=http://127.0.0.1:4173 node scripts/inspect-watch.mjs docs/screenshots/fullscreen
```

Проверка генератора в Blender с контрольной посторонней коллекцией, двумя построениями и сравнением экспортов описана в отчёте. Для пересоздания GLB достаточно команды из [MODEL.md](docs/MODEL.md); Blender не нужен для просмотра сайта.

Часы — авторская демонстрационная конструкция, а не копия конкретной исторической модели и не инструкция по ремонту. Стрелки зафиксированы на 10:10 для предметной композиции; механическая симуляция хода и звук не входят в демонстрацию.
