# KARpOV — карманная коллекция №01

Коммерческая презентация авторских карманных часов: крупный первый экран, плавная 3D-история с пятью остановками и три живые модели ниже — баланс, заводная головка и колёсная передача. Бренд **KARpOV** нанесён на геометрию циферблата, внутренней крышки и платины. Выбор латунного, стального или графитового корпуса сохраняется между посещениями.

Стек: React / TypeScript / Vite, императивный Three.js, GSAP ScrollTrigger и Lenis. Модели, шрифты и изображения локальные; серверная часть для просмотра не требуется.

## Запуск

Нужен Node.js 22.12 или новее. В папке проекта:

```bash
./start.sh
```

Адрес: **http://127.0.0.1:4173/**. При отсутствии зависимостей или сборки скрипт подготовит их. После изменения исходников выполните `npm run build`. Для разработки — `npm run dev`, http://127.0.0.1:5173/. На другом компьютере: `npm ci`, `npm run build`, `npm run preview`.

Живые модели требуют WebGL 2. До первого нарисованного кадра и при ошибке виден соответствующий предметный poster; характеристики и выбор исполнения остаются доступны. Blender и Python для просмотра не нужны. Публикация и Git push не выполнялись.

## Что работает

- **Крупное начало:** часы показаны ближе, затем камера плавно отходит к первому ракурсу деталей. Размер телефона адаптирован отдельно.
- **Пять остановок:** «Облик», «Корпус», «Циферблат», «Механизм», «Целое». Поза действительно неподвижна внутри плато; между ними движение обратимо. Кнопки этапов теперь плавно ведут к остановкам за 1.5–2.4 с, а ввод колесом, касанием или клавишей прерывает переход.
- **3D-обзор:** абсолютный обход 423° desktop / 407° mobile, крупный план передачи и возврат к общей композиции. Ракурсы остановок показывают лицевую сторону или три четверти. В макро края корпуса намеренно выходят из кадра.
- **Ещё три живые 3D-модели:** баланс колеблется, заводная головка раскрывает рифление и вал при прокрутке, шестерни передачи вращаются. Это отдельная процедурная геометрия, а не анимация плоского изображения.
- **Рассмотреть:** OrbitControls, прямой ползунок, сборка/разборка, пауза, сброс камеры и native dialog с каталогом 47 групп. Ручная конфигурация сохраняется при возврате в историю.
- **Исполнение корпуса:** латунь, сталь и графит меняют реальные PBR-материалы основной модели и соответствующую карточку. Эмаль, стрелки и механизм сохраняют материалы. Выбор хранится в localStorage, если оно доступно.
- **Сохранить выбор:** скачивает текстовую карточку локально, без отправки данных, оформления заказа или оплаты. Цена, наличие, запас хода и водозащита не выдуманы.

## Плавность и стоимость рендеринга

Lenis использует `lerp .085` и общий GSAP ticker. ScrollTrigger передаёт единственный **raw progress**, а `evaluateStoryPose` преобразует его в **pose progress**. Переходы стали длиннее; quintic применяется в timeline, а yaw камеры интерполируется по pose линейно, чтобы не сжимать полный поворот повторным easing.

| Остановка | Интервал raw progress | Неподвижная pose progress |
| --- | ---: | ---: |
| Облик | 0–6% | 0% |
| Корпус | 25–30% | 22% |
| Циферблат | 51–56% | 46% |
| Механизм | 75–80% | 75% |
| Целое | 96–100% | 100% |

Mapping одинаков в истории и ручном режиме. На плато основной viewer повторно использует уже нарисованный кадр, пока поза и камера не изменились; raw-обновление само по себе больше не вызывает WebGL draw.

У трёх нижних моделей **один общий renderer и canvas**. Он создаётся лениво рядом с видимыми разделами и перемещается в наиболее видимый слот. Вне экрана и в скрытой вкладке его ticker останавливается. Reduced motion оставляет статический 3D-ракурс, отключает непрерывное движение и по умолчанию открывает компактный основной viewer. Совпадающие posters страхуют загрузку и сбой, но не заменяют готовые живые сцены. Подробнее — [DESIGN.md](docs/DESIGN.md).

## Файлы

- `src/app/App.tsx` — основная презентация, навигация и конфигурация.
- `src/components/CollectionPage.tsx` — коммерческие разделы и сохранение карточки.
- `src/components/DetailScene.tsx`, `src/scene/DetailSceneManager.ts` — слоты живых моделей и общий нижний renderer.
- `src/scene/detailModels.ts` — процедурные баланс, головка и передача.
- `src/animation/storyTimeline.ts`, `src/animation/scrollCoordinator.ts` — плато и общий scroll-clock.
- `src/scene/WatchScene.ts`, `src/scene/CameraRig.ts` — основной GLB, PBR, кадрирование и выбор деталей.
- `public/models/pocket-watch.glb`, `assets/blender/pocket-watch.blend` — основная модель KARpOV; в этой итерации не изменена.
- `public/images/karpov-*.webp` — предметные изображения и соответствующие 3D-моделям posters.

Основной GLB: **47 групп, 187 898 треугольников, 136 примитивов, 5 324 520 байт**. Все carrier rest-TRS сохранены. [Модель](docs/evidence/karpov-model.json), [геометрия новых узлов](docs/evidence/detail-models.json), [рендеры posters](docs/evidence/detail-renders.json).

Рендеры воспроизводятся через `node scripts/render-product.mjs` и `node scripts/render-detail-models.mjs` при запущенном dev-сервере 5173.

Финальный браузерный прогон: **9/9 passed в одном полном запуске**, без повторов и пропусков; [сводка](docs/evidence/browser-live-scenes-summary.json), [сырой JSON](docs/browser-live-scenes-full.json). Сняты **8 целевых production-кадров** нового opening и нижних сцен: [метрики](docs/screenshots/live-scenes/metrics.json). Ошибок страницы/console, внешних запросов и горизонтального overflow нет. Подробности и ограничения — в [VERIFICATION.md](docs/VERIFICATION.md).

```bash
npm run typecheck
npm test -- --reporter=json --outputFile=docs/evidence/unit-live-scenes.json
npm run verify:model
npm run build
PW_BASE_URL=http://127.0.0.1:4173 npm run test:browser
PW_BASE_URL=http://127.0.0.1:4173 node scripts/inspect-commerce.mjs --focus
```

Playwright использует `/usr/bin/google-chrome`; другой путь задаётся через `CHROME_BIN`. SwiftShader и viewport-эмуляция не являются замером аппаратного GPU или проверкой физического телефона.

```bash
python3 scripts/package-release.py
cp artifacts/hod-vremeni.zip artifacts/KARpOV.zip
python3 scripts/save-checkpoint.py
```

Архивы — `artifacts/hod-vremeni.zip` и брендовая копия `KARpOV.zip`; атомарные резервные копии — `artifacts/checkpoints/latest.zip` / `previous.zip`. Версия до увеличения часов и новых живых сцен сохранена отдельно: Git **53ffa43**, `artifacts/checkpoints/before-live-scenes.zip`.

После выключения исходники, Git и ZIP остаются на диске; сервер снова запускается через `./start.sh`. Контекст продолжения — [WORK_STATE.md](WORK_STATE.md), инструкции — [AGENTS.md](AGENTS.md). Настройки аккаунтов, env-файлы, `.git`, `.tools` и `node_modules` в архивы не входят.

Основная модель — авторская демонстрационная конструкция. Стрелки стоят на 10:10 для предметной композиции; движение новых узлов показывает их характер, а не калиброванную инженерную симуляцию реального хода.
