# Ход времени

Локальная интерактивная экспозиция механических карманных часов. Крупная модель стоит по центру: прокрутка обратимо раскрывает корпус, циферблат, мосты и передачу. Плашки объясняют видимые узлы. Режим «Рассмотреть» позволяет остановиться, вращать часы и выбирать любой из 47 узлов.

В локальной рабочей папке подготовлен архив `artifacts/hod-vremeni.zip` с исходниками приложения, редактируемой моделью, статической сборкой, отчётами и снимками. Архив, `dist/`, установленные зависимости и локальные настройки инструментов не хранятся в Git; сборка воспроизводится из исходников и `package-lock.json`.

## Доработка по промпту

[PROMPT_REDESIGN_SCROLL_WATCH.md](PROMPT_REDESIGN_SCROLL_WATCH.md) реализован в этой итерации. Сохранены стек и 47 групп исходной модели; добавлены фаски зубьев и мостов, расточки, реальные прорези стрелок, углубление малых секунд и ленточная пружина. Экспорт: 188 570 треугольников, 136 примитивов, GLB 5 345 484 байта. Редактируемый `.blend`, генератор и манифест включены. Снимки четырёх viewport, сравнение моделей и фактические проверки — в [отчёте](docs/VERIFICATION.md).

## Сохранение и продолжение после выключения

[WORK_STATE.md](WORK_STATE.md) хранит состояние проекта, результаты проверок и точку продолжения. [AGENTS.md](AGENTS.md) указывает следующему запуску агента прочитать этот файл. Исходники и локальные Git-коммиты остаются на диске; сервер после выключения запускается снова через `./start.sh`.

```bash
python3 scripts/save-checkpoint.py
```

Команда атомарно обновляет `artifacts/checkpoints/latest.zip`, проверяет CRC и сохраняет предыдущую версию как `previous.zip`. Внутри есть время UTC, Git HEAD, исходники, сборка, модель и документация. Она не выполняет сетевых запросов и не включает установки инструментов или настройки аккаунтов. Готовый архив для передачи отдельно обновляется командой `python3 scripts/package-release.py`.

## Запуск

Нужен Node.js 22.12 или новее. Откройте терминал в папке проекта и выполните:

```bash
./start.sh
```

Скрипт сам выполнит `npm ci` и `npm run build`, если зависимости или сборка отсутствуют. В исходной локальной рабочей папке они уже подготовлены.

Адрес приложения: **http://127.0.0.1:4173/**. Скрипт откроет браузер, если в системе доступен `xdg-open`. Остановить сервер можно сочетанием Ctrl+C. Также в папке есть ярлык `Ход времени.desktop` для запуска приложения в терминале. Публичная публикация не выполнялась.

Режим разработки с обновлением при изменениях:

```bash
npm run dev
```

Адрес разработки: http://127.0.0.1:5173/. Для воспроизводимой установки на другом компьютере с Node.js 22.12+ — `npm ci`, затем `npm run build` и `npm run preview`. Единственный менеджер пакетов проекта — npm; точные версии фиксирует `package-lock.json`.

Для просмотра нужны современный браузер и WebGL 2. **Blender, Python и MCP для работы сайта не нужны.** Все необходимые ресурсы, включая шрифты, модель и изображение на случай ошибки, локальные. При недоступном WebGL показываются изображение и объяснение, а неработающие элементы управления отключаются.

## Управление

- **История** — режим по умолчанию. Обычная прокрутка страницы управляет разборкой и камерой; вертикальный свайп по часам прокручивает документ. Длина секции — 5 экранов на desktop и 4 на телефоне.
- **Разборка часов:** нативный ползунок 0–100% с шагом 0,1%. Arrow меняет значение, Home собирает, End разбирает. В истории он перемещает документ к соответствующему месту. Из-за округления scroll до CSS-пикселя progress может отличаться от выбранного процента на долю пиксельного шага.
- **Собрать / Разобрать:** в истории запускают переход документа; **Пауза** прекращает его. Wheel, touch и клавиатурный ввод сразу прерывают программное движение.
- **Рассмотреть:** сохраняет текущую степень разборки и камеру. Прокрутка больше не меняет модель; работают прямой ползунок, кнопки, выбор деталей и вращение мышью/пальцем. Колесо и два пальца приближают только внутри сцены этого явно выбранного режима.
- **Продолжить историю:** синхронизирует документ с ручным progress и плавно возвращает только камеру в сценарный ракурс, сохраняя конфигурацию часов.
- **Сбросить вид:** восстанавливает камеру, сохраняя степень разборки.
- **Подписи деталей:** на desktop одновременно не более двух, по бокам предмета. На телефоне — одна актуальная подпись в постоянной области под canvas. Скрытые за корпусом узлы не просвечивают подписями.
- **Выбор:** нажмите на деталь или на её название под сценой. Повторное нажатие, клик по пустой области или кнопка снятия выделения убирают выбор.

При настройке ОС «Уменьшение движения» сайт сразу предлагает компактный ручной режим без длинной секции. Кнопки устанавливают конфигурацию сразу; ручной ползунок работает напрямую. Историю можно включить явно, при этом автоматический обход камеры отключён. Скрытая вкладка останавливает программные переходы. Resize сохраняет режим и progress; перезагрузка учитывает сохранённую позицию истории.

## Что внутри

React, TypeScript, Vite и императивная сцена Three.js; серверная часть не требуется. `ScrollCoordinator` передаёт одному `ProgressController` нормализованный progress из обычного scroll. В ручном режиме координатор отсоединяется. Чистая функция вычисляет позиции, quaternion и многооборотные углы колёс из проверенного манифеста, без накопления смещений. Камера вписывает реальные границы мешей. Three.js рендерит по требованию, ограничивает DPR и снижает его до 1 при медленном рендере.

- `src/app/` и `src/components/` — интерфейс, управление и сведения об узлах.
- `src/scene/` — загрузка GLB, студийный свет, материалы, камера, выбор и подписи с учётом перекрытия.
- `src/animation/` — детерминированные трансформации, единый progress и координатор нативной прокрутки.
- `src/data/story.ts` — шесть этапов и короткие функции видимых узлов.
- `src/data/watch-parts.json` — манифест всех 47 деталей и русские объяснения.
- `public/models/pocket-watch.glb` — готовая автономная 3D-модель.
- `assets/blender/pocket-watch.blend` — редактируемый исходник.
- `assets/blender/build_watch.py` и `export_watch.py` — воспроизводимые создание и экспорт; подробности в [docs/MODEL.md](docs/MODEL.md).
- [SETUP_REPORT.md](SETUP_REPORT.md) — проверка 48 навыков и подготовка окружения.
- [docs/BLENDER_MCP.md](docs/BLENDER_MCP.md) — реальная MCP-проверка и граница обнаружения инструментов текущей сессией Codex.
- [ASSET_SOURCES.md](ASSET_SOURCES.md) — происхождение ресурсов и лицензии.
- [docs/VERIFICATION.md](docs/VERIFICATION.md) — фактические проверки и ограничения QA.
- `docs/screenshots/` — desktop/mobile на 0/25/50/75/100% и сравнение с исходной моделью.

## Проверки

```bash
npm run typecheck
npm test
npm run verify:model
npm run build
```

Браузерная проверка при запущенном локальном сервере:

```bash
PW_BASE_URL=http://127.0.0.1:4173 npm run test:browser
```

В этом окружении Playwright использует установленный `/usr/bin/google-chrome`. На другой машине путь можно передать через `CHROME_BIN`. Эмуляция мобильного viewport не заменяет проверку на физическом телефоне.

Повторяемая серия из 20 снимков и измерений проекции при запущенном dev-сервере:

```bash
node scripts/inspect-watch.mjs docs/screenshots/scroll
```

Проверка генератора в Blender с контрольной посторонней коллекцией, двумя построениями и сравнением экспортов описана в отчёте. Для пересоздания GLB достаточно команды из [MODEL.md](docs/MODEL.md); Blender не нужен для просмотра сайта.

Часы — авторская демонстрационная конструкция, а не копия конкретной исторической модели и не инструкция по ремонту. Стрелки зафиксированы на 10:10 для предметной композиции; механическая симуляция хода и звук не входят в демонстрацию.
