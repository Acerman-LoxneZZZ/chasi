# KARpOV — карманная коллекция №01

Интерактивная презентация авторских карманных часов. Сначала на экране только большие часы; прокрутка превращает их в полноэкранную 3D-историю. Камера обходит и приближает предмет, пять неподвижных остановок дают рассмотреть детали. Ниже — коллекция, три живые модели механизма и примерка инициалов на задней крышке. В финале часы снова собираются перед подписью **KARpOV** и повтором истории. Выбор латунного, стального или графитового корпуса и инициалы сохраняются между посещениями; тихий звук механизма включается отдельно.

Стек: React / TypeScript / Vite, императивный Three.js, GSAP ScrollTrigger и Lenis. Модели, шрифты и изображения локальные; серверная часть для просмотра не требуется.

## Запуск

Нужен Node.js 22.12 или новее. В папке проекта:

```bash
./start.sh
```

Адрес: **http://127.0.0.1:4173/**. При отсутствии зависимостей или сборки скрипт подготовит их. После изменения исходников выполните `npm run build`. Для разработки — `npm run dev`, http://127.0.0.1:5173/. На другом компьютере: `npm ci`, `npm run build`, `npm run preview`.

В текущем сеансе 4173 занят другим проектом, KARpOV запущен на **http://127.0.0.1:4174/**. Для повторного запуска используйте `PORT=4174 ./start.sh`.

На Windows (PowerShell) из папки проекта:

```powershell
npm ci
npm run build
npm run preview -- --port 4174 --strictPort
```

Если зависимости и сборка уже подготовлены, достаточно последней команды. Для браузерных проверок и снимков на Windows задайте `$env:CHROME_BIN='C:\Program Files\Google\Chrome\Application\chrome.exe'` и `$env:PW_BASE_URL='http://127.0.0.1:4174'`.

Живые модели требуют WebGL 2. До первого нарисованного кадра и при ошибке виден соответствующий предметный poster; характеристики и выбор исполнения остаются доступны. Blender и Python для просмотра не нужны. Исходники отправлены в [GitHub](https://github.com/Acerman-LoxneZZZ/chasi), ветка main. Сайт работает локально; облачный деплой не выполнялся.

## Что работает

- **Погружение:** живой canvas занимает весь экран. В начале и во время пролётов нет постоянного заголовка, меню и панелей. Мышь у верхнего или нижнего края, одиночное нажатие на сцену либо Tab вызывают управление; после паузы оно уходит. Клавиатурный фокус и открытое управление сохраняют доступ.
- **Смотреть историю:** кнопка в вызываемом меню запускает 42-секундный просмотр через настоящий scroll, с остановками и плавным движением камеры. Пауза мышью, wheel, касание, клавиша или ползунок прерывают его. Можно продолжить с того же места или повторить после конца.
- **Крупное начало:** камера с FOV 30°, opening fill 1.13; небольшой выход за края намеренный. Затем камера отходит к первому ракурсу деталей. Телефон адаптирован отдельно.
- **Пять остановок:** «Облик», «Корпус», «Циферблат», «Механизм», «Целое». Поза неподвижна внутри плато; между ними движение обратимо. Характеристики видны только в остановках после первого кадра. Кнопки этапов плавно ведут к ним за 2.4–8.5 с; ручной ввод прерывает переход.
- **3D-обзор:** абсолютный обход 423° desktop / 407° mobile, крупный план передачи и возврат к общей композиции. Ракурсы остановок показывают лицевую сторону или три четверти. В макро края корпуса намеренно выходят из кадра.
- **Ещё три живые 3D-модели:** баланс колеблется, заводная головка раскрывает рифление и вал при прокрутке, шестерни передачи вращаются. Это отдельная процедурная геометрия, а не анимация плоского изображения.
- **Рассмотреть:** OrbitControls, прямой ползунок, сборка/разборка, пауза, сброс камеры и native dialog с каталогом 47 групп. Выбор кликом по 3D действует только здесь; в истории нажатие вызывает управление. Ручная конфигурация сохраняется при возврате в историю.
- **Исполнение корпуса:** латунь, сталь и графит меняют реальные PBR-материалы основной модели и соответствующую карточку. Эмаль, стрелки и механизм сохраняют материалы. Выбор хранится в localStorage, если оно доступно.
- **Примерка гравировки:** до восьми символов на живой задней крышке, с кириллицей, латиницей и цифрами. Текст следует существующей детали модели, обновляется и в основном viewer; пустое поле убирает надпись. Это визуальная примерка, а не подтверждение производственной услуги.
- **Финальная сборка:** после спецификации 47 групп плавно становятся целым; камера завершает отъезд, затем появляются KARpOV и «Повторить историю». Обратная прокрутка разворачивает тот же путь. Во время движения на сцене только часы.
- **Звук механизма:** короткий тихий tick/tock синтезируется Web Audio. По умолчанию выключен, в том числе после перезагрузки. Включается кнопкой в меню или финале; при уходе со всех 3D-сцен и скрытии вкладки приостанавливается. Звук не управляет анимацией.
- **Сохранить выбор:** скачивает текстовую карточку с исполнением и инициалами локально, без отправки данных, оформления заказа или оплаты. Цена, наличие, запас хода и водозащита не выдуманы.

## Плавность и стоимость рендеринга

Lenis использует `lerp .075` и общий GSAP ticker. ScrollTrigger передаёт единственный **raw progress**, а `evaluateStoryPose` преобразует его в **pose progress**. Новый cinematicEase разгоняется мягко, затем долго держит равномерную скорость и тормозит перед остановкой. Пик скорости для того же перехода снижен на треть относительно прежнего quintic, без второго progress-follower. Это математическое свойство траектории, не замер FPS.

| Остановка | Интервал raw progress | Неподвижная pose progress |
| --- | ---: | ---: |
| Облик | 0–6% | 0% |
| Корпус | 25–30% | 22% |
| Циферблат | 51–56% | 46% |
| Механизм | 75–80% | 75% |
| Целое | 96–100% | 100% |

Mapping одинаков в истории и ручном режиме. На плато основной viewer повторно использует уже нарисованный кадр, пока поза и камера не изменились; raw-обновление само по себе больше не вызывает WebGL draw.

У пяти нижних слотов — трёх узлов механизма, крышки и финальной сборки — **один общий renderer и canvas**. Для крышки и финала лениво загружается один общий экземпляр исходного GLB. Всего на странице две WebGL-системы: основная и общая нижняя. Вне экрана и в скрытой вкладке нижний ticker останавливается; крышка и финал рисуются только при изменении ракурса, исполнения или надписи. Reduced motion оставляет статический 3D-ракурс, компактный основной viewer и уже собранный финал без длинной прокрутки. Совпадающие posters страхуют загрузку и сбой, но не заменяют готовые живые сцены. Подробнее — [DESIGN.md](docs/DESIGN.md).

Подготовка ближайших сцен разбита на idle-задачи, шейдеры компилируются через compileAsync. Геометрия нижних моделей сохранена; batching сокращает calls баланса 17→12, головки 16→12, передачи 38→24. GPU-таймер читает только готовые результаты; адаптивный DPR учитывает реальную задержку кадра. Ограничение 30 Hz при перегрузке действует и во время scroll, последнее положение не теряется. Сохранение scroll в sessionStorage объединено до одного раза за 250 ms. Подробности и ограничения — [SCROLL_PERFORMANCE.md](docs/SCROLL_PERFORMANCE.md).

## Файлы

- `src/app/App.tsx` — основная презентация, навигация и конфигурация.
- `src/components/CollectionPage.tsx` — коммерческие разделы и сохранение карточки.
- `src/components/PersonalizationSection.tsx`, `src/components/FinaleSection.tsx` — примерка и финальная сцена.
- `src/components/DetailScene.tsx`, `src/scene/DetailSceneManager.ts` — слоты живых моделей и общий нижний renderer.
- `src/scene/GpuTimer.ts`, `src/scene/detailEnvironment.ts` — неблокирующие GPU-замеры и загрузка локального освещения без runtime PMREM нижних сцен.
- `src/scene/PersonalWatchModel.ts`, `src/scene/Engraving.ts` — общий нижний GLB и надпись на крышке.
- `src/scene/detailModels.ts` — процедурные баланс, головка и передача.
- `src/animation/storyTimeline.ts`, `src/animation/scrollCoordinator.ts` — плато и общий scroll-clock.
- `src/animation/finaleTimeline.ts`, `src/audio/MechanismSound.ts` — абсолютная сборка и звук по явному включению.
- `src/scene/WatchScene.ts`, `src/scene/CameraRig.ts` — основной GLB, PBR, кадрирование и выбор деталей.
- `public/models/pocket-watch.glb`, `assets/blender/pocket-watch.blend` — основная модель KARpOV; в этой итерации не изменена.
- `public/images/karpov-*.webp` — предметные изображения и соответствующие 3D-моделям posters.

Основной GLB: **47 групп, 187 898 треугольников, 136 примитивов, 5 324 520 байт**. Все carrier rest-TRS сохранены. Надпись добавляет во время работы два треугольника и один draw call; исходный GLB не изменён. [Модель](docs/evidence/karpov-model.json), [геометрия узлов](docs/evidence/detail-models.json), [резервные ракурсы крышки и финала](docs/evidence/personal-posters.json).

Рендеры воспроизводятся через `node scripts/render-product.mjs`, `node scripts/render-detail-models.mjs` и `node scripts/render-personal-watch.mjs` при запущенном dev-сервере 5173.
