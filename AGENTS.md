# Продолжение проекта «Ход времени»

Перед изменениями прочитай `WORK_STATE.md` — там последняя сохранённая точка, результаты проверок и оставшаяся работа. Основное задание находится в `PROMPT_REDESIGN_SCROLL_WATCH.md`. Не начинай проект заново.

Сохраняй текущий стек React / TypeScript / Vite / императивный Three.js, название, палитру, локальные шрифты, 47 основных групп модели и экспортные rest-TRS. Не подменяй живую 3D-сцену изображениями. Облачная публикация и Git push не запрошены.

Пользователь предпочитает самостоятельную работу без лишних вопросов и подтверждений. Продолжай уже разрешённые действия; обязательные ограничения инструментов и безопасности сохраняют силу.

После значимых этапов обновляй `WORK_STATE.md`, сохраняй локальную контрольную точку через `python3 scripts/save-checkpoint.py` и фиксируй завершённые изменения локальным Git-коммитом. Резервные ZIP находятся в `artifacts/checkpoints/`, готовый архив — `artifacts/hod-vremeni.zip`. Не включай в архив настройки аккаунтов, `.git`, `.tools`, `node_modules`, `.codex`, `.aws` или `.env`.

Не переноси результаты старых прогонов на новый код. Используй фактические JSON-отчёты и проверяй, какая сборка была протестирована. Software SwiftShader и эмуляция viewport/touch не являются проверкой физического телефона или аппаратного GPU.
