# Продолжение проекта KARpOV

Перед изменениями прочитай `WORK_STATE.md` — там последняя сохранённая точка, результаты проверок и оставшаяся работа. Основное задание находится в `PROMPT_REDESIGN_SCROLL_WATCH.md`. Не начинай проект заново.

Последний запрос пользователя разрешил и требует Three.js + GSAP ScrollTrigger + Lenis по видео Paragon. Новый запрос: коммерческий бренд KARpOV, остановки с характеристиками и дальнейшие разделы. Старое название и ограничение «только fullscreen» отменены. Сохраняй React / TypeScript / Vite / императивный Three.js, общий ticker Lenis / ScrollTrigger, локальные шрифты, 47 основных групп модели и экспортные rest-TRS. Не подменяй живую 3D-сцену изображениями. В pose-progress есть осознанный макро-интервал 54–96%; raw scroll теперь проходит через storyTimeline с пятью hold-плато: там края корпуса могут выходить из кадра ради крупного плана центрального колеса; общие остановки вписаны; новый запрос разрешает более крупный intro с небольшим выходом за границы. Не восстанавливай старый constant-fit во время макро. Пользователь отдельно разрешил Git push готовой итерации в origin/main (Acerman-LoxneZZZ/chasi). Облачная публикация сайта не запрошена.

Пользователь предпочитает самостоятельную работу без лишних вопросов и подтверждений. Продолжай уже разрешённые действия; обязательные ограничения инструментов и безопасности сохраняют силу.

После значимых этапов обновляй `WORK_STATE.md`, сохраняй локальную контрольную точку через `python3 scripts/save-checkpoint.py` и фиксируй завершённые изменения локальным Git-коммитом. Резервные ZIP находятся в `artifacts/checkpoints/`, готовый архив — `artifacts/hod-vremeni.zip`. Не включай в архив настройки аккаунтов, `.git`, `.tools`, `node_modules`, `.codex`, `.aws` или `.env`.

Не переноси результаты старых прогонов на новый код. Используй фактические JSON-отчёты и проверяй, какая сборка была протестирована. Software SwiftShader и эмуляция viewport/touch не являются проверкой физического телефона или аппаратного GPU.

Последняя итерация: к крупному intro и трём живым procedural 3D-сценам добавлены примерка гравировки, финальная сборка перед KARpOV и звук механизма по явному включению. Сохранять две WebGL-системы: основной WatchScene и один общий нижний renderer/canvas для пяти слотов. Крышка и финал используют один ленивый экземпляр исходного GLB; надпись следует back_cover. Сохранять lazy visibility/reduced-motion cleanup и тишину по умолчанию; не возвращать картинки вместо активных 3D-моделей.
