## Blender MCP

Сервер и совместимый аддон установлены и проверены реальным MCP SDK-клиентом: initialize, list_tools, чтение сцены, создание своей тестовой коллекции и куба, изменение положения и материала, повторное чтение, снимок и удаление только тестовых сущностей. Подключение — stdio к MCP-серверу и TCP `127.0.0.1:9876` к аддону. Телеметрия отключена.

Конфигурация Codex добавлена только в `.codex/config.toml` проекта. Ранее этого файла не было, резервная копия не требовалась; `~/.codex/config.toml` и другие пользовательские настройки не менялись. `codex mcp list --json` обнаруживает включённый `pocket_watch_blender`.

**Ограничение текущей AI-сессии:** интерфейс инструментов текущего разговора не предоставляет hot reload MCP, а CLI подтверждает доступность новых инструментов после следующего запуска клиента. Поэтому регистрация и внешняя MCP-проверка завершены, но обнаружение Blender-инструментов непосредственно в уже открытой сессии Codex не заявляется. Внешний SDK-клиент не выдаётся за встроенный инструмент этого разговора.

Подробности и проверяемые свидетельства: [docs/BLENDER_MCP.md](docs/BLENDER_MCP.md), [blender-environment.json](docs/blender-environment.json). Для просмотра приложения Blender, MCP и Python не нужны.
