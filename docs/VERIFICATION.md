# Проверка «Ход времени» — история прокрутки

29 октября 2026 года. Проверена production-сборка на `http://127.0.0.1:4173/`, entry `index-DcTpbxT3.js`. Это новые проверки доработанного сайта; результаты первой итерации сохранены отдельно в [VERIFICATION_V1.md](VERIFICATION_V1.md).

## Итог

- **41/41 unit-тест**, 5 файлов: абсолютные позы, точная обратная сборка всех 47 групп, clamp/slerp/многооборотное вращение, mobile spacing, единственный progress, scroll mapping, смена владельца, resize, reload, reduced motion, кадровая камера. [JSON](evidence/unit-v2.json).
- **Типы и production-сборка проходят** через `npm run build`; предупреждений Vite нет. SHA исходного GLB совпадает с SHA модели в `dist`. [Проверка сборки](evidence/build-v2.json).
- **16 браузерных сценариев подтверждены**, состав прогонов и источник результата каждого сценария указаны ниже. [Сводка](evidence/browser-v2-summary.json).
- **20 финальных viewport-снимков**: 0/25/50/75/100% на четырёх размерах. Во всех измерениях границы всех мешей внутри canvas, горизонтальный overflow отсутствует, ошибок страницы/console и внешних запросов приложения нет. [Все измерения](screenshots/scroll/metrics.json).
- GLB: **5 345 484 байта**, **47 групп**, **95 узлов**, **47 мешей**, **12 материалов**, **188 570 треугольников**, **136 примитивов**. Прямые измерения renderer в 20 состояниях также показывают 136 draw calls и 188 570 треугольников. Бюджеты 8 MB / 200k / 150 соблюдены. [Экспорт](evidence/model-validation.json).
- Два построения Blender дают одинаковые GLB и манифест. Чужой mesh, трансформации, material slots, shader graph и цвета не меняются даже при совпадении имени материала и признака владельца. [Двойная проверка](evidence/blender-v2-build.json).
- Все проверенные текстовые сочетания, включая плашку с opacity 0,78 на границе этапов, проходят 4,5:1; минимум **6,24:1**. [Контраст](evidence/contrast-v2.json).

## Реальное окружение

Chrome 155 headless на Linux, Playwright 1.64.1. WebGL 2 через `ANGLE / Vulkan / SwiftShader Device (Subzero)`, DPR 1 в серии снимков. Это программный renderer, а не замер аппаратного GPU. Шрифты, GLB и окружение работают локально. Полные userAgent и renderer сохранены в [метриках](screenshots/scroll/metrics.json).

Телефон проверен viewport/touch-эмуляцией 390×844, включая настоящие touch-события через CDP. Физические iPhone/Android, Safari/Firefox и настоящие screen reader не проверялись. Частота кадров на физических устройствах не измерялась.

## Браузерные сценарии и состав прогонов

В полном прогоне финальной сборки прошли 15 сценариев. Один сценарий кнопок был повторён после изменения тестовой доставки событий: ожидание Playwright на динамической кнопке и CDP wheel на SwiftShader могли занимать целый программный переход. **Код приложения и сборка при повторе не менялись.** Это сводка полного прогона и целевого повтора, а не заявление об одном полностью зелёном 16-сценарном запуске.

Пауза мышью проверена нативным pointer click по измеренным координатам неподвижной кнопки; клавиатурная пауза — нативным Space. В повторе отмена программного перехода колесом проверяется через настоящий DOM wheel listener синхронной доставкой события, затем через нативную прокрутку колеса. Медленная/быстрая нативная прокрутка и touch отдельно проходят без такого обхода доставки. Это ограничение метода автоматизации явно отделено от аппаратной проверки.

## Сравнение и модель

[Галерея до/после](screenshots/comparison.html) содержит исходную и улучшенную геометрию в одном окружении Three.js на 0/75/100%, viewport 1440×1000. Интерфейс скрыт только в сравнительной съёмке; сайт остаётся настоящей интерактивной сценой. Ракурсы близкие, масштаб вычисляется по границам конкретной модели.

Первый экран исходного сайта снят до изменения файлов: [до редизайна](screenshots/before/original-desktop-0.png). Финальный центрированный экран: [после редизайна](screenshots/scroll/1440x1000-0.png). На сравнительных рендерах видны более плавный ободок, крупные цифры, прорези стрелок, углубление секунд, фаски зубьев, втулки и ленточная пружина. Исправлен серый треугольный блик от усреднённых нормалей Boolean-плоскости эмали.

Blender CLI/Python реально выполнил генерацию и экспорт. SHA256 финального GLB: `e7a922c003ce0215e01d37544be733e4a905e002be46456ef90e5d228ebe87ef`. Подробности геометрии и воспроизведения — в [MODEL.md](MODEL.md); граница нативного MCP — в [BLENDER_MCP.md](BLENDER_MCP.md). Авторская конструкция не заявляет историческую инженерную точность или физическую симуляцию хода. Браузерный материал стекла экономично имитирует прозрачность без физического transmission-прохода.

## Воспроизведение и сохранение

```bash
npm run build
npm test
npm run verify:model
./start.sh
```

В другом терминале:

```bash
PW_BASE_URL=http://127.0.0.1:4173 npm run test:browser
PW_BASE_URL=http://127.0.0.1:4173 node scripts/inspect-watch.mjs docs/screenshots/scroll
```

Для сохранения результата:

```bash
python3 scripts/package-release.py
python3 scripts/save-checkpoint.py
```

Контекст продолжения — `WORK_STATE.md`, инструкция автоматического чтения — `AGENTS.md`. Локальные Git-коммиты и атомарные ZIP `artifacts/checkpoints/latest.zip` / `previous.zip` сохраняют работу между запусками. В архивы не входят установки инструментов, node_modules, `.git`, настройки аккаунтов или env-файлы. Облачная публикация и push не выполнялись.
